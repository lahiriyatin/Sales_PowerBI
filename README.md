# Sales Performance Dashboard (Power BI)

### Overview
An interactive Power BI dashboard designed to monitor key **sales and profit metrics** across regions, products, and customer segments.  
It provides clear insights into total sales, units sold, costs, and profitability with dynamic filtering options.

---

### Dashboard Preview
![Sales Performance Dashboard](https://raw.githubusercontent.com/lahiriyatin/Sales_PowerBI/refs/heads/main/image.png)

---

### Key Metrics
- **Total Units Sold**  
- **Total Sales** 
- **Total COGS**
- **Total Profit**

---

### Key Features
- Month-wise filtering to analyze seasonal performance.  
- **Regional analysis map** for visualizing sales distribution.  
- **Top products funnel** showing high-performing items.  
- **Bar and line charts** comparing manufacturing cost vs. sale price.  
- **Treemap** for customer segment and regional contribution.  

---

### Tools Used
- Power BI Desktop  
- Power Query (data transformation and cleaning)  
- DAX (calculated measures and KPIs)  
- Interactive visuals and custom slicers

### How to Use
1. Download the `.pbix` file from this repository.  
2. Open it in **Power BI Desktop**.  
3. Use slicers to filter by month, region, or product category.  
4. Hover over visuals for detailed data insights.
